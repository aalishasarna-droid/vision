# 🏭 Vision

> **Industrial Acoustic Anomaly Detection on the Edge**

Vision is an end-to-end TinyML application that inspects industrial machinery through sound. It converts raw audio into Log-Mel spectrograms, processes them using a lightweight INT8-quantized Autoencoder (< 256 KB), profiles edge performance metrics, and presents live anomaly diagnostics through a React + Vite dashboard.
